# V5 literature register

## Dual-CyCon Net

- Source: [Dual-CyCon Net](https://arxiv.org/abs/2012.11532)
- Relevant reported ideas: phase alignment, moving-average/zero-crossing
  preprocessing, alpha=100/beta=1 flattening, peak/knee selection, temporal and
  frequency branches, and cycle-consistency regularization.
- V5 status: literature-informed adaptation only. The paper's measurement-level
  any-phase aggregation, reported label counts, split protocol, exact code
  revision, and complete training details are not identical to this repository's
  signal-level VSB protocol.
- Prohibited interpretation: V5 MCC cannot be compared numerically with the
  paper's reported MCC as if preprocessing and statistical units were equal.

## Provenance policy

No public VSB-trained weights or unreviewed external implementation are used.
Any future external code must have a pinned revision, compatible license,
security review, reproducible preprocessing, and a documented deviation record
before it can enter the V5 candidate set.
