# Experimentos

Each experiment must declare at least:

- dataset and version;
- partition/split;
- representation;
- model;
- hyperparameters;
- seed;
- imbalance strategy;
- threshold-selection rule;
- configuration version.

The primary metric will be MCC. Recall, F1, PR-AUC, ROC-AUC, and Accuracy will
be secondary metrics.
