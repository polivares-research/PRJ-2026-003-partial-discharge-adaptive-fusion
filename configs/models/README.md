# Modelos previstos

The architecture must support comparing models by representation:

- 1D-CNN and 1D-ResNet;
- 2D-CNN;
- GRU u otros modelos secuenciales;
- XGBoost;
- Random Forest;
- SVM;
- MLP.

Future adaptive fusion will be configured in `configs/experiments/` and kept
separate from individual baselines.
